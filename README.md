# 三月机 · 星穹铁道「自由宇宙」

一台装进**酒馆助手**（SillyTavern 的 JS-Slash-Runner 插件）里的手机。

它让角色卡里的人能**给你发消息**、能**记住你**、能**群聊**，
你跟他们聊过的事还会**流回正文**——不是另开一个聊天窗，是长在你的酒馆里。

## 装之前

| 必须 | 说明 |
|---|---|
| SillyTavern | 能正常跑起来的版本就行 |
| **酒馆助手（JS-Slash-Runner）** | **4.11.3 或更高**。三月机靠它读写聊天变量、调 API、注入正文 |
| 一个支持 function calling 的模型 | 不用也行，但「检查更新 / 自动加好友」那条路就没法走 |

**先备份你的聊天**：右上角 ☰ → 导出聊天。三月机自己的存档写在聊天变量 `三月机` 里，
理论上不碰你的正文，但**备份永远是对的**。

## 装法 A · 一行（推荐）

酒馆 → 扩展（积木图标）→ **酒馆助手** → **脚本库** → 新建脚本
→ 名字随便（比如「三月机」）→ 脚本内容贴这一行：

```js
import 'https://cdn.jsdelivr.net/gh/tiankong166/march7-machine@v1.0.0/index.js'
```

保存 → **启用** → **F5 刷新**。右下角出现一个能拖的手机图标。

### 打不开 / 一直不出现？用带镜像的版本

jsdelivr 在国内时通时不通，所以留了四个入口。把下面整段贴进脚本库，它会自己挨个试：

```js
/* 三月机 · 一行安装（四个镜像自动回退） */
(async () => {
  const U = [
    'https://cdn.jsdelivr.net/gh/tiankong166/march7-machine@v1.0.0/index.js',
    'https://gcore.jsdelivr.net/gh/tiankong166/march7-machine@v1.0.0/index.js',
    'https://fastly.jsdelivr.net/gh/tiankong166/march7-machine@v1.0.0/index.js',
    'https://testingcf.jsdelivr.net/gh/tiankong166/march7-machine@v1.0.0/index.js',
  ];
  for (const u of U) {
    try { await import(u); return; } catch (e) { console.warn('[三月机] 镜像没通，换下一个：', u); }
  }
  console.error('[三月机] 四个镜像全都没通。检查网络，或改用「装法 B」。');
})();
```

入口自己也会换镜像（真下载 `march7.js` 的那一步），所以这里只要有一个通就行。
四个都不通的时候，酒馆右下角会**弹一条红条**告诉你「加载失败」，不会让你干等。

> **为什么不是把代码粘成一坨？**
> 手机本体 4MB 多，粘进脚本库那种编辑器里会很卡，而且以后更新要重粘。
> 一行 import 的好处是：我这边发版，你只改一个版本号。

## 装法 B · 酒馆扩展

酒馆 → 扩展 → **安装扩展** → 填这个地址：

```
https://github.com/tiankong166/march7-machine
```

装完 **F5 刷新**。它会出现在 `public/scripts/extensions/third-party/march7-machine/`。

**A 和 B 只装一种**。两个都开会出现两份手机互相抢界面（代码里有防重复，但别赌）。

## 第一次用

1. 打开你想玩的那个聊天
2. 点右下角手机图标（**可以拖**，拖到哪就停在哪）
3. 回桌面 → **通讯**
4. 打开手机会自动读一次**智库 · 角色档案**，把档案里有的人都放进「**待确认**」
   - ✓ 加入通讯录（以后能聊天）
   - ✗ 忽略
   - 想再拉一次：通讯页右上角 ➕ →「同步智库档案」

**角色档案里写了谁，通讯录里就有谁。** 手机自己不另存一份资料，所以不存在
「两套数据对不上」。档案里没写的人，名片是空的——去智库补上，再同步一次。

## 正文和手机怎么互相喂

### 正文 → 手机（让角色主动发消息）

正文里让 AI 输出这样一个块，手机会弹通知、把消息落进对应会话：

````
```手机
符玄: 你到底什么时候回来？
[落云居三人] 爻光: 小师弟，桂花糕凉了哦
竟天：明日卯时来司天灵台
```
````

- 一行一条，`名字: 内容`（中文冒号也认）
- 前面加 `[群名]` 就是发到那个群，群不存在会自动建
- 普通代码块（```python 之类）不会被误吃
- **关掉**：设置 → 行为 → 正文触发弹窗

### 手机 → 正文（让你聊的事被剧情接住）

手机里聊完，下一轮正文生成前会自动注入一小段：

```
【手机 · 本轮】
时间：星历7780年4月16日 15:40 · 玉阙仙舟·太卜司落云居庭院
符玄：你要去哪里？说清楚。……罢了，我拦不住你，但至少告诉我方位。
群「落云居三人」 爻光：去罗浮？带上我呀，我认得路。
（以上是主角刚在手机上发生的事。正文可以自然地引用它，但不要复述整段对话…）
```

- **一次性**，只影响下一轮
- **只注入没注入过的新消息**（按消息 id 记账），不会一遍遍重复
- 这一轮手机没动静时，给一小段「近况」当背景，而不是留空
- **关掉**：设置 → 行为 → 回写正文 ／ 手动来一次：设置 → 操作 → 立刻回写

### 时间用的是「故事时间」

手机上的钟**走正文里的时间**，不是现实时间。每轮正文结束后会再看一眼，
所以剧情推进了，手机会跟上。想用现实时间：设置 → 行为 → 关掉「用故事时间」。

## 它读什么、写什么

**读**（全从你自己的档案来）

| 来源 | 读什么 |
|---|---|
| 智库 · 角色档案 | 长相 / 穿着 / 身份 / 经历 / 它知道什么 / 它不知道什么 |
| 智库 · 重要地点、重要势力 | 世界状态 |
| 正文楼层 | 最近 6 楼，给联系人当「最近发生的事」 |
| 聊天变量 | 开场面板写的「开局设定」（拿主角名） |

**写**（只写它自己的东西）

- 聊天变量 `三月机`：通讯录 / 会话 / 消息 / 设置
- 可选：把手机里的事压成一段注入下一轮正文（一次性）
- 可选：导出成世界书《三月机-备份》（只有你自己点才会写）

它**不往任何外部表里写，也不碰你的世界书**（除了你自己点的备份）。

### 关于「会不会把我的存档冲掉」

这条在开发时被专门堵过（详见代码里的 `sawSavedState` 闸门）：

- **没成功读到过存档之前，一律不写盘**——只会记一个待写标记，等真的读到了再写
- 空会话、空名字的坏数据会被扫掉，不会渲染成白屏
- 导出 JSON 时自动抹掉 API Key（Key 只存在当前聊天的变量里）

## 常见问题

**Q：右下角什么都没有。**
先按 F12 看 Console 有没有 `[三月机]` 开头的日志。
- 有「加载失败：四个 jsdelivr 入口全都不通」→ 网络问题，用装法 B，或换网络/代理
- 有「等不到酒馆助手」→ 酒馆助手没装好或没启用
- 什么都没打 → 脚本没启用（脚本库里那个开关是灰的？）

**Q：出现两个手机 / 图标。**
装法 A 和 B 同时开了。删掉一个，刷新。

**Q：表情包是空白 / 只显示名字。**
表情图是**跟脚本放在同一个目录的 `emotes/` 下**（不是嵌在代码里）。
装法 A 时它是 CDN 上的 `emotes/`——如果你只下载了 `march7.js` 而没带 `emotes/`，
就会没图。用装法 A 或 B 的完整仓库都不会有问题。

**Q：更新了，界面还是旧的。**
jsdelivr 会缓存。要么在地址里用**具体版本号**（`@v1.0.0` 这种，别用 `@main`），
要么等几分钟缓存过期，要么 Ctrl+F5。

**Q：手机里的时间和正文对不上。**
设置里确认「用故事时间」是开的；检查更新接口配了吗？
时间是从正文（含思维链）里读的，读不到会显示 `--:--` / 「时间未知」，
不会拿现实时间硬凑。

**Q：能不能不配 API？**
可以。手机会用「正文里的 ```手机 块」当消息来源，不花 API。
但「每轮检查正文里有没有新消息 / 时间变化」那条路要第二个接口，配个便宜模型就行。

## 关于体积和画质（说清楚，免得被骂偷懒）

表情包一共 **473 个**（37 个分类），来自游戏内聊天表情。仓库里放的是 **256px WebP**：

- 界面上表情最大显示 **96px**（聊天气泡），面板格子约 55px —— 256px 已是 **2.7 倍超采样**
- 和旧版 256px PNG 逐像素对比过：**放大 2 倍看，肉眼看不出差别**（差异只出现在硬边的亚像素抖动上）
- 单张平均 88KB → 27KB，457 张 PNG 从 **55MB** 压到 **约 12MB**
- 16 张 GIF 动图**原样保留**，没有重新编码
- 800×800 的原图没有被删除，只是没放进仓库

如果你想要原图：`emotes/` 里放原图，跑 `node tools/build-emotes.mjs` 就会重新生成
（这一步需要 Python + Pillow）。

## 仓库里有什么

```
index.js        ← 酒馆助手脚本库的入口（就是你要 import 的那一行）
march7.js       ← 手机本体（构建产物，4MB 多，别手改）
manifest.json   ← 酒馆扩展的清单
style.css       ← 扩展样式占位（真样式由脚本自己注入）
emotes/         ← 表情图（跟脚本同目录，手机按自己的地址去取）
```

## 更新 / 回滚

- **装法 A**：把脚本里那个版本号改掉，保存，F5
- **装法 B**：酒馆扩展页 → 找到 march7-machine → 更新（或删掉重装）

想留在旧版：把版本号写成旧的那个（比如 `@v0.9.0`），jsdelivr 上每个 tag 都还在。
